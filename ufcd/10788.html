UFCD 10788 - Fundamentos da Linguagem SQL

Durante a frequência da UFCD de Fundamentos de Bases de Dados, consolidei um conjunto abrangente de competências teóricas e práticas essenciais para a modulação, estruturação e manipulação de dados. Compreendi a diferenciação entre os vários modelos de bases de dados — destacando os sistemas relacionais (como MySQL, PostgreSQL e SQL Server) e não relacionais (NoSQL, como MongoDB) —, bem como o papel fundamental de um Sistema de Gestão de Base de Dados (SGBD) para interagir com a informação. Aprofundei o ciclo completo de planeamento de uma base de dados, percorrendo as fases de análise de requisitos, modelo concetual, modelo lógico e modelo físico, aplicando conceitos de cardinalidade (1:1, 1:N e N:N).

No modelo relacional, compreendi a importância crucial do conceito de chaves para a organização e integridade dos dados: a chave primária (PK) identifica cada registo de uma tabela de forma única e inequívoca, garantindo que não existem linhas duplicadas e que cada entidade é exclusiva; por sua vez, a chave estrangeira (FK) estabelece a ligação entre tabelas, ao guardar num registo o valor da chave primária de outra tabela, assegurando a integridade referencial do sistema. Adicionalmente, explorei as restantes restrições de integridade, como as de domínio, chave e vazio.

Pratiquei também a linguagem SQL (Structured Query Language) tanto ao nível de DDL (Data Definition Language) para criação e alteração de estruturas com CREATE, ALTER e DROP, como de DML (Data Manipulation Language) para execução das operações CRUD (INSERT, SELECT, UPDATE e DELETE). Adquiri ainda fluência em técnicas avançadas de consulta, incluindo a utilização de agrupamentos (GROUP BY), filtros sobre grupos (HAVING), pesquisa por padrões (LIKE), ordenação (ORDER BY), eliminação de duplicados (DISTINCT) e subconsultas com os operadores ANY e ALL. Estes conhecimentos constituem uma mais-valia determinante para o meu futuro, assumindo uma relevância central no plano profissional enquanto programador informático. A capacidade de desenhar esquemas relacionais eficientes e sem redundâncias é a base de qualquer aplicação ou software sustentável, desde sistemas empresariais (ERP) até plataformas web e soluções móveis. Dominar a escrita correta de queries SQL e a criação de chaves e índices garante a otimização de desempenho das aplicações, permitindo uma integração fluida entre o código aplicacional e a camada de dados. Do ponto de vista pessoal e de organização do raciocínio estruturado, a aprendizagem da modulação de dados desenvolveu a minha capacidade de abstração, análise crítica de problemas e estruturação lógica da informação. Em suma, as competências adquiridas nesta UFCD conferem-me a preparação técnica e a confiança necessárias para projetar, gerir e otimizar bases de dados com rigor e eficiência no mercado de trabalho da programação.

Na minha vida profissional estes conhecimentos já teriam dado muito jeito, porque para gestão de uma empresa usando o excel, embora seja muito eficaz, mas torna-se mais complexo e trabalhoso do que criando uma base de dados em SQL, até porque criando uma base de dados podemos depois fazer a parte do front end, que é tornar a base de dados graficamente "bonita", mais simples de trabalhar e mais clean do que usando o excel.

Relativamente ao formador, gostei da forma como deu a matéria, os exercícios foram muito adequados e bem estruturados.
